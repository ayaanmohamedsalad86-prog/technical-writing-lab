## Procedure

**Step 1: Open GitHub**

Open your web browser and navigate to https://github.com.

**Expected result:** The GitHub homepage appears on your screen.

**Step 2: Sign in**

Click the Sign in button and enter your GitHub username and password.

**Expected result:** Your GitHub dashboard opens.

**Step 3: Create a repository**

Click the plus (+) icon in the top-right corner and select New repository.

**Expected result:** The repository creation page appears.

**Step 4: Enter repository details**

Type a repository name in the Repository name field, for example, `my-first-project`.

**Expected result:** Your repository name appears in the name field.

**Step 5: Set repository visibility**

Select Public or Private depending on your preference.

**Expected result:** Your selected visibility option is displayed.

**Step 6: Initialize the repository**

Select the Add a README file checkbox.

**Expected result:** The README option is selected.

**Step 7: Create the repository**

Click the Create repository button.

**Expected result:** Your new repository page opens.

**Step 8: Edit the README file**

Open the README file, click the pencil icon, and add a short description of your project.

**Expected result:** Your README contains your project description.

**Step 9: Save your changes**

Click Commit changes, enter the commit message `Add project description`, and confirm the commit.

**Expected result:** Your changes are saved, and the commit appears in your repository history.
